HOW TO USE ON ANOTHER PC - QUICK GUIDE
================================================================================

STEP 1: TRANSFER THE APP
-------------------------
Windows: Copy dist\CreditSystem_Windows_Portable.zip
Android: Copy build\app\outputs\flutter-apk\app-release.apk

Transfer Methods:
- USB flash drive
- Cloud storage (Google Drive, OneDrive, Dropbox)
- Email attachment
- Network share
- Bluetooth (for Android)

STEP 2: INSTALL ON NEW PC/PHONE
--------------------------------
Windows:
1. Extract CreditSystem_Windows_Portable.zip
2. Open the folder
3. Double-click credit_app.exe
4. If Windows blocks it: Click "More info" > "Run anyway"

Android:
1. Enable "Install from Unknown Sources" in Settings
2. Tap the APK file
3. Tap "Install"
4. If Play Protect warns: Tap "Install anyway"

STEP 3: FIRST TIME SETUP
-------------------------
1. Create your first user account
2. Set a 4-digit PIN code
3. Start managing customers!

STEP 4: TRANSFER YOUR DATA (OPTIONAL)
--------------------------------------
If you want to move existing data:

Easy Method - Using Backup:
1. Old device: Settings > Backup & Restore > Create Backup
2. Save the backup file
3. Transfer backup file to new device
4. New device: Settings > Backup & Restore > Restore Backup
5. Select your backup file

Advanced Method - Copy Database:
Windows: Copy %APPDATA%\credit_app\credit_app.db
Android: Requires root access (not recommended)

TROUBLESHOOTING COMMON ISSUES
================================================================================

Windows - "App won't start":
- Extract all files together (don't run from ZIP)
- Right-click credit_app.exe > Properties > Unblock
- Run as Administrator
- Check Windows Defender

Android - "Can't install":
- Enable "Install from Unknown Sources"
- Check Android version (5.0+ required)
- Ensure enough storage space

Both - "Forgot PIN":
- Use backup/restore to recover data
- Or delete database (loses all data)
