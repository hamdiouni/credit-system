## Troubleshooting

### Issue: HTML doesn't open
**Solution**: Check default browser setting in Windows

### Issue: Arabic still looks wrong
**Solution**: Make sure browser opened (HTML method), not direct PDF

### Issue: Can't save as PDF
**Solution**: Press Ctrl+P, select "Save as PDF" as printer

### Issue: Fonts look bad
**Solution**: Check internet connection (Google Fonts need internet)
