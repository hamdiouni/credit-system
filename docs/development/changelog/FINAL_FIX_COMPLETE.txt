WHAT WAS THE PROBLEM?
================================================================================

ISSUE: Balance credit was being consumed but debt was NOT reduced

Example of the BUG:
- Customer has 10 TND balance credit
- Add 12 TND new debt
- WRONG RESULT: Shows 12 TND debt (balance disappeared but debt not reduced!)
- CORRECT RESULT: Should show 2 TND debt (10 TND balance consumed)

ROOT CAUSE:
The transaction provider was:
1. Adding the FULL credit transaction (12 TND)
2. Adding a negative balance credit transaction (-10 TND)
3. Calculation: 12 - 10 = 2 TND ✓ (correct in math)
4. BUT UI showed "Credit: 12 TND" because it displayed the transaction amount

================================================================================
THE FINAL FIX
================================================================================

SOLUTION: Don't add the full credit transaction when balance exists!

NEW LOGIC:

Scenario 1: Balance covers ALL debt
- Customer has 10 TND balance
- Add 8 TND debt
- Action: Only add -8 TND balance credit transaction (NO credit transaction)
- Result: 2 TND balance remaining, 0 TND debt ✓

Scenario 2: Balance PARTIALLY covers debt
- Customer has 10 TND balance
- Add 12 TND debt
- Action: Add 2 TND credit transaction + -10 TND balance credit transaction
- Result: 0 TND balance, 2 TND debt ✓

Scenario 3: NO balance
- Customer has 0 TND balance
- Add 12 TND debt
- Action: Add 12 TND credit transaction
- Result: 0 TND balance, 12 TND debt ✓

FILE CHANGED: lib/providers/transaction_provider.dart
